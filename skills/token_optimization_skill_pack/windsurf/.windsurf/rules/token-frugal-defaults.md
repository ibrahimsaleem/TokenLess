# Token-Frugal Defaults

- Start with search, symbols, grep, and file names before reading full files.
- Read only the smallest relevant snippets.
- Avoid generated files, lockfiles, vendor folders, build outputs, logs, and unrelated open tabs unless required.
- For large tasks, produce a short plan before edits.
- Use skills for multi-step procedures instead of keeping long instructions always-on.
- Use MCP only for targeted external context; avoid broad MCP exploration.
- Summarize durable findings into a compact handoff before switching tasks.
