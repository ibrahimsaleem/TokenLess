# token-audit

Description: Run a quick token-efficiency audit before a large Cascade task.

1. State the user goal in one sentence.
2. List the minimum context required.
3. List the files or tools that should be avoided.
4. Decide whether a Skill, Rule, AGENTS.md, Memory, or MCP tool is the right mechanism.
5. If MCP is needed, define the smallest possible query.
6. Produce a 5-step execution plan.
7. Ask the user only if the scope is destructive, security-sensitive, or materially ambiguous.
