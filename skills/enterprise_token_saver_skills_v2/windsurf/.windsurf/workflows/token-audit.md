# token-audit

Run a quick token optimization review.

1. List always-on files: `AGENTS.md`, `.windsurf/rules`, project rules, MCP config, memory.
2. Identify files/rules that are long, duplicate, stale, or generic.
3. Identify noisy commands likely to flood context.
4. Identify whether RTK, Token Optimizer, or code-review-graph should be used.
5. Produce a short remediation plan.
