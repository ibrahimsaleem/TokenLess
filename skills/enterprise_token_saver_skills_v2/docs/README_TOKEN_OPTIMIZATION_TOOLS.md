# Token Optimization Tools Referenced

## 1. Token Optimizer
Use for structural token waste, memory health, compaction quality, CLAUDE.md/MEMORY.md audits, unused skills, MCP bloat, prompt-cache safety, and local dashboarding.

Suggested enterprise use:
- Pilot for Claude Code power users.
- Use audit mode before installing many skills/MCP servers.
- Track quality degradation and compaction handoffs.
- Review privacy/license posture before broad deployment.

## 2. RTK
Use for runtime command-output compression. Best for noisy commands such as git, tests, grep, tree, docker, package managers, and logs.

Suggested enterprise use:
- Start with non-destructive commands.
- Prefer WSL/Linux/macOS for full hook behavior.
- Measure whether compressed outputs preserve debugging quality.
- Do not use compression where exact output is required for compliance evidence.

## 3. code-review-graph
Use for graph-guided code review and repo navigation. Best for monorepos, large repos, PR review, blast-radius analysis, and onboarding.

Suggested enterprise use:
- Build graph in repo onboarding.
- Exclude generated/vendor files.
- Use MCP integration for Claude Code/Windsurf/VS Code tools.
- Review local index/security posture before use on sensitive repos.
