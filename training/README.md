# Employee training: token optimization for AI applications

These paths teach engineers to ship **cost-efficient** and **context-efficient** LLM features. Each level lists objectives, reading order, and one hands-on exercise.

## Paths

| Level | Audience | Folder |
|-------|----------|--------|
| 1 — Beginner | Anyone shipping first LLM features | [level-1-beginner/](level-1-beginner/) |
| 2 — Intermediate | Owners of prompts, agents, or IDE workflows | [level-2-intermediate/](level-2-intermediate/) |
| 3 — Expert | Platform, infra, or staff engineers | [level-3-expert/](level-3-expert/) |

## Suggested schedule

- **Week 1:** Level 1 (2–3 hours total).
- **Week 2–3:** Level 2 with a pilot service (instrument one API route).
- **Week 4+:** Level 3 elective for platform team; adopt one OSS helper (graph, RTK, or token-optimizer) per org policy.
