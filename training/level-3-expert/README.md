# Level 3 — Expert

## Objectives

- Design **RAG** with evaluation, not vibes.
- Build or govern **MCP** servers with strict budgets.
- Run **pilots** of graph-based review and terminal compression tooling.
- Define org-wide **metrics** and **lint** for prompts and agent configs.
